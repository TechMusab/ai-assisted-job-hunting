# AI-Assisted Job Hunting

An AI-powered frontend application that helps job seekers discover, analyze, match, and manage job opportunities.

This project is being developed as a capstone for the **Frontend AI Engineering** track, with a focus on combining modern frontend engineering with practical AI-powered user experiences.

## Planned AI Features

* **AI-powered job search** – Natural language queries to find relevant opportunities
* **Job description analysis** – Extract key requirements, skills, and culture insights
* **Resume-to-job matching** – AI-powered compatibility scoring and gap analysis
* **AI resume feedback** – Actionable suggestions based on specific job requirements
* **Application assistance** – Draft tailored cover letters and responses
* **AI career assistant** – Ongoing guidance for job search strategy and skill development

## Frontend Focus

* Modern responsive UI
* Accessible user experiences
* AI interaction patterns
* Streaming AI responses
* Loading, error, and empty states
* Structured AI outputs
* Reusable component architecture
* State management
* AI-assisted development

## Tech Stack

* React
* TypeScript
* Node.js
* AI/LLM APIs

Additional technologies will be documented as the project evolves.
